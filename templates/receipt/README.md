# תבניות קבלות - Receipt Templates

תיקייה זו מכילה את התבניות להפקת מסמכי קבלות בפורמט A4.

## קבצים

- `receipt-template.html` - תבנית HTML של הקבלה
- `receipt-styles.css` - עיצוב CSS של הקבלה

## משתנים (Variables)

התבנית משתמשת במשתנים הבאים שיש להחליף בנתונים אמיתיים:

### פרטי חברה
- `{{USERCOMPANYNAME}}` - שם החברה
- `{{USERID}}` - מספר עוסק (ח.פ)
- `{{USERADDRESS}}` - כתובת
- `{{PHONE}}` - טלפון
- `{{EMAIL}}` - אימייל
- `{{DOMAIN}}` - אתר אינטרנט

### פרטי לקוח
- `{{CLIENTNAME}}` - שם הלקוח
- `{{BUSINESSID}}` - ח.פ / ת.ז של הלקוח

### פרטי מסמך
- `{{RECEIPTNNUMBER}}` - מספר קבלה
- `{{Datecreation}}` - תאריך יצירה
- `{{DATE}}` - תאריך תשלום
- `{{TIME}}` - שעת הפקה
- `{{DESCRIPTION}}` - תיאור
- `{{AMOUNT}}` - סכום
- `{{TOTAL}}` - סה"כ
- `{{NOTES}}` - הערות

## שימוש

1. טען את קובץ ה-HTML
2. החלף את כל המשתנים בנתונים אמיתיים
3. קשר את קובץ ה-CSS
4. הפק PDF או הדפס

## הדפסה

התבנית מותאמת להדפסה בפורמט A4 עם:
- גודל: 210mm x 297mm
- שוליים: 20mm מכל צד
